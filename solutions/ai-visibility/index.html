Solution

Make website guidance clearer for AI systems—without overstating what one file can do.

An llms.txt file can publish concise guidance about a site. It does not guarantee crawling, inclusion or citation. Treat it as one maintainable signal alongside accessible pages, crawlable links and accurate metadata.
