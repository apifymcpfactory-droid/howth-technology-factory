A workflow you can follow.

Preview first, review the scope, then create the result.

1. Check your dataset

Paste CSV or flat-row JSON and load it locally. Catch duplicate headers, missing numeric values and ambiguous category names before charting.

2. Tell a clear story

Map the right columns, choose a chart family, palette and labels. Add source notes, highlights and annotations; use shared-scale small multiples when useful.

3. Create and deliver

Create new editable Figma marks and typography. Export SVG, spreadsheet-safe CSV, raw-cell JSON or a report that records plotting and aggregation choices.

Know what it supports.

Four chart families. No maps, log scales, statistical modeling, forecasts, live data connections or direct PNG/PDF downloads. Categorical lines use equal spacing, not date scaling. Dense labels may be shortened; full values remain in reports. Up to 500 data rows with lower per-chart limits. Native Figma typography and rendering are still being tested.
