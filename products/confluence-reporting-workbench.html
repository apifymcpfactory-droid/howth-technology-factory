A real build, with clear remaining gates.

Implementation has begun on the core calculation, query and spreadsheet engines. The integrated interface, native Confluence permissions, licensing, exports and realistic scale acceptance are still being verified. The product has not been submitted for review.

Bring the data together

The intended workflow starts with typed imports and explicit source checks, so the report can explain where its rows came from.

Shape a reusable report

Filters, spreadsheet calculations, pivots and charts are planned as parts of one reporting workflow. Availability will follow integration and native testing.

Review the next release

Source checks and release comparisons are intended to help teams identify changes before sharing the next report. These are development goals, not validated production features.

Data and platform access

Native permissions, storage, data handling and deletion behaviour are not yet certified. A product-specific disclosure will be finalized from the implemented and tested behaviour before release. Do not upload private data to an unofficial preview.
