What we are building

A Unity workbench in development for saving game progress, inspecting records, testing migrations and recovering earlier versions. The features below describe the intended product, not a finished release.

Inspect saved progress

Review records and their history so it is easier to understand what a save contains.

Rehearse a migration

Try changes on a copy, compare the result and keep earlier versions available.

Check recovery

Test interrupted writes and recovery before shipping a game update.

Development progress

Local core and customer-server checks are passing. Compilation inside Unity, player tests, full feature coverage and interface testing remain unfinished. No Unity package has been submitted.

Complete feature coverage, a clear interface, useful documentation and marketplace checks are required before submission. Performance and compatibility claims will follow testing.

Where it runs

Local use is designed to work offline. Optional cloud storage is being developed for the customer’s own server. The customer supplies hosting, HTTPS and player authentication, and pays any hosting costs. Supported Unity versions and platforms remain unverified.
