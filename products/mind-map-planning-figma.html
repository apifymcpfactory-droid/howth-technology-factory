A workflow you can follow.

Preview first, review the scope, then create the result.

1. Bring the thinking

Paste an indented outline, Markdown checklist or supported JSON project. Add notes, owners and statuses without leaving the local workflow.

2. Choose the shape

Preview a balanced mind map, vertical tree or organisation chart. Collapse branches for a focused view while retaining their underlying data.

3. Build a useful board

Create editable topic cards and static connectors. Read a saved board back into the plugin and rebuild only when the generated board has no conflicting manual edits.

Know what it supports.

A local planning tool, not a full Xmind replacement. No Xmind file compatibility, AI, scheduling, notifications or hosted collaboration. Connectors are static and do not follow cards moved manually. JSON is the full round-trip format; Markdown import supports hierarchy and checkboxes. Native Figma testing is in progress.
