Structure the evidence before engineering review.

ReproCase keeps the case identity, build context, one explicit reproduction action, observed result and expected and actual outcomes together. Missing evidence remains visible rather than becoming a false pass.

Check completeness

Review complete, incomplete and invalid states with explicit errors and warnings.

Preserve a recovery copy

Replacement saves retain the previous valid report so the current evidence can be recovered or compared.

Export the handoff

Create versioned JSON and readable Markdown below the host project's local Saved/ReproCase directory.

Important boundaries

ReproCase is an Unreal Editor tool, not a packaged-game runtime component. Version 1.0 records one explicit reproduction action. It does not automatically capture screenshots, video, logs or attachments; monitor play sessions; identify root causes; certify fixes; or replace project backups. Review user-entered project context before sharing an export.
