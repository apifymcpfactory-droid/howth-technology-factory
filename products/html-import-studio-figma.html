3. Create a new starting point

Create new fixed-position text and shape layers. Keep the original document content intact and review font fallback and wrapping.

Know what it supports.

No live website URL capture, scripts, remote assets or webfonts. Each width creates a separate fixed-position design, not reconstructed auto layout. Embedded PNG/JPEG images are supported. Borders, gradients, shadows, transforms and some text details need review. Up to 1,200 elements and 1.5 MB HTML.
