Owner. Budget. Next milestone.

A project can need its own owner, target date, account reference or release checklist. ProjectKit is being built for this project-level information, without turning each value into an issue field.

Start with a template

Begin with a delivery, customer account or release layout, then adapt its fields to the project.

Preview the layout

See the field layout while configuring it, before filling in the project’s values.

Use typed values

Text, long text, number, date, select, checkbox and URL fields provide a consistent structure.

Works at project level.

  • Project metadata only, with one schema per project, up to 30 fields and up to 20 options per dropdown.
  • Project administrators can change definitions and values; users with Browse Projects can read all fields. There is no field-level restricted visibility.
  • Export saved project values to CSV. Jira issue fields, JQL, cross-project reports, imports and prior-version recovery are outside this build.
  • Jira Cloud is the target platform. No Jira Data Center edition is available.
Privacy & data

The development app is built for Atlassian Forge hosting and storage. Its records contain the field definitions and entered project values, a revision number and a last-save timestamp. The backend checks Jira project permissions; it does not retrieve issues, attachments or user directories.

The build has no external backend, AI processing or app analytics, and does not log entered values. All project viewers can read its fields, so they must not contain secrets or information restricted to particular people.

Project administrators can clear values or remove fields. CSV export downloads saved values to the user’s device. Previous versions are not retained for recovery. Deployment and Forge’s storage lifecycle still require verification before public release.

Browser demo: the interactive sample uses fictional data held only in the current page’s memory. Changes reset on refresh. It makes no Jira requests and does not save to Jira or Forge storage.

This marketing page uses Google Analytics. The website privacy notice explains website analytics and contact messages separately from the app and browser demo.

Does it replace Jira custom fields?

No. ProjectKit is for metadata attached to a project. It does not create or replace fields on Jira issues.
