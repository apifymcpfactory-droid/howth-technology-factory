Keep your choices together.

A collection helps you find an icon once. A kit helps you repeat the same choices across a product. SVG Icons | HTF is being built around that second step: reusing a small, consistent set.

Search without a network round trip

Search bundled Lucide icons by name or common aliases. The plugin does not call a remote icon API.

Insert editable artwork

Set a size from 12 to 256 pixels, choose a hex colour and adjust the stroke before inserting an SVG-based icon.

Reuse a saved selection

The development build supports up to 20 saved kits with 200 icons per kit, plus replacement of eligible selected icons. Paid access has not been activated for public use.

Know what replacement changes.

  • Targets classic plugins in Figma Design. Figma Make and FigJam are outside this build.
  • The initial library is bundled. Kits are private to the local Figma client; there is no team sync, cloud backup or user-uploaded pack support.
  • Replacement supports up to 100 selected square frames inserted by SVG Icons | HTF and preserves the outer frame. Locked or stretched frames, frames with unsupported layout, masks or child types, and component or instance contents are skipped. Manual vector-geometry edits are not detected and will be replaced.
  • Stroke is defined on the original 24-pixel grid and scales with icon size.
  • Figma installation and the editor itself have their own connection requirements. The plugin’s icon search runs locally.
Privacy & data

The development build bundles its icons and sets the plugin’s allowed network domains to none. It contains no analytics, AI calls, external icon service or Howth account.

Saved kits use Figma clientStorage, local to the Figma client. The current palette stays in memory. Use the saved-kit Delete control to remove a kit; Clear palette removes the current selection from the plugin panel.

Inserting or replacing icons changes the open Figma document. Deleting a kit does not remove icons already inserted into a design.

The build integrates Figma’s native payment interface for paid features; seller setup, native checkout opening and cancellation have been verified in development. Public checkout is not yet available. The plugin does not receive card details.

Browser demo: the canvas and Pro access are simulated. Saved demo kits use this browser’s local storage; Delete removes a kit. Clear this site’s browser data to remove all demo kits. Canvas items reset on refresh. The demo does not contact Figma or process payments.

This marketing page uses Google Analytics. The website privacy notice explains website analytics and contact messages separately from the plugin.

Does offline search make Figma itself work offline?

No. Offline refers to searching the icon library bundled with the plugin. Figma has its own connection and application requirements.

Which icon licenses apply?

The bundled Lucide library uses the ISC license, with MIT notices for icons derived from Feather. The complete third-party license notices are available here and included with the build. Preserve applicable notices when redistributing the artwork.
