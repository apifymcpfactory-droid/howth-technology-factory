What to expect

PNG and WebP preserve transparency; JPG uses a white background. SVG is exported natively without size optimisation. Only JPG and WebP use target-size quality search. There is no guarantee every target can be met. ZIP includes exported assets, a preview index and a JSON report. Preview thumbnails are not full-resolution exports. No original layers are changed.
