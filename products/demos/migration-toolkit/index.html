      Help with your migration

      Inspection and preview are free. Pro adds applying migrations, saved recipes, JSON/CSS export and an editable reference-page generator. Pro uses Figma's native one-time checkout.

      Supported: recognised scalar variable bindings; solid paint colour bindings; supported effect bindings; text-range typography bindings; paint, text, effect and grid style references; optional local variable aliases and paint-style definitions; unbound solid colours and selected spacing/radius values.

      Components: compatible flat structures with matching child names and compatible text/boolean properties. Nested instances, slots, scaled instances and unsupported overrides are skipped. The plugin does not promise preservation of every possible override or prototype relationship.

      Text-content bindings and font-identity variable bindings are excluded. Text-style migration requires available fonts and skips manual typography overrides. Main component contents are excluded from layer edits. Raw values with the same number or colour can have different meanings.

      Safety: use a duplicate/version backup. A preview can become stale. Keep Figma open while running. Recovery is limited to supported properties recorded in the current plugin session. Imported target definitions remain in the document when restoring a run.

      Privacy: no analytics, AI calls, external API keys or network requests from this plugin. Figma provides the editor, asset imports, client storage and checkout. Recipes and target packs stay on this client. Downloads may contain private asset/layer names and IDs; review them before sharing. No support messages are sent automatically.
