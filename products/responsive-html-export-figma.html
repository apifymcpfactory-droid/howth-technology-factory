A workflow you can follow.

Preview first, review the scope, then create the result.

1. Inspect selected frames

Review your selected screens, ordinary text, auto layout and image assets before exporting. Unsupported features are called out.

2. Choose the handoff

Export supported auto layout as flex structure, or preserve fixed coordinates. Absolute overlays keep their separate positioning.

3. Download the local pack

Get HTML, CSS, local PNG assets and a report in a ZIP. Ordinary text remains text; the source Figma file is not changed.

Know what it supports.

A static developer starting point. No JavaScript application, backend, React, automatic breakpoint merging or guaranteed pixel parity. Referenced fonts are not bundled. Review complex fills, effects, masks and raster fallbacks. Up to 12 selected roots and 2,500 layers.
