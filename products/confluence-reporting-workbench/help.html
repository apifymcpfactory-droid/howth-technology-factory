Reporting Workbench for Confluence | HTF

A useful report, step by step.

Product guide. Learn the reporting workflow and supported limits. Check the product page for Marketplace availability.

Create your first report

  1. In Confluence, open a space, then Apps → Reporting Workbench | HTF. You must be signed in and able to access the page that will own your report.
  2. Enter the saved page's link or numeric page ID and select Check page access. Editing requires permission to update that page. A draft page must be published or saved first.
  3. Give the report a clear title, such as “Monthly delivery budget”. Open the import step and choose a supported file or paste CSV, TSV or JSON. Review the replacement confirmation before continuing.
  4. Check column types, missing values and formula errors. The first row should contain column names. Supported formulas use familiar cell references such as =SUM(B2:B4).
  5. Filter or sort the rows you need. To compare totals, open the pivot step, select a grouping column, a numeric measure and an aggregation.
  6. Select Save release. Wait for Saved and up to date before leaving. Unsaved changes exist only in the current browser view.

Saved releases remain available after you reopen the app. Unsaved drafts do not survive a browser refresh.

Review changes and keep control

The release view lets you compare the draft with saved data. Choose a unique matching column when rows have moved. At most five saved releases are retained. Restoring an older retained release creates a new current release. If another editor saves first, keep your draft and review the latest release before trying again.

Reports use the permissions of their owning Confluence page. All fields in a report share that access; there is no private-cell permission. Referenced report pages are checked separately when data is requested. Removing someone's page access is the way to revoke access to that page's reports. Previously viewed browser data and downloads cannot be recalled by later permission changes. Fresh requests recheck current access.

Delete report requires confirmation and removes the current report and its retained releases, not the Confluence page. Export any data you need first.

Supported formats and limits

  • Datasets: up to 2,000 rows, 50 columns and 10,000 cells, subject to the report-size limit. A report can reference five saved sources. Each page can hold 20 reports.
  • Files: CSV, TSV, JSON and supported XLSX worksheets. XLSX files are limited to 5 MB compressed and 20 MB expanded. Merged cells, shared formulas, VBA, external links and workbook styling are not supported.
  • Calculations: 48 documented deterministic functions. Unsupported functions return visible errors. This is not universal Excel compatibility.
  • SQL: a restricted, read-only SELECT over the supplied report data. It does not connect to a database or execute writes or arbitrary scripts.
  • Saved report: up to 300 KB of normalized report data and 200 KB in its compressed storage record. A shorter dataset can still exceed these limits if cells contain long text.
  • Charts and joins have additional category, series and computation limits. Filter or split a report when prompted.
Supported formula functions

SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, ROUND, IF, IFERROR, COUNTIF, SUMIF, LEFT, RIGHT, TRIM, CONCATENATE, VLOOKUP, INDEX, MATCH, AND, OR, NOT, ABS, COUNTIFS, SUMIFS, AVERAGEIF, AVERAGEIFS, LEN, LOWER, UPPER, ISBLANK, ISNUMBER, ISTEXT, ROUNDUP, ROUNDDOWN, SQRT, POWER, PRODUCT, DATE, DATEVALUE, YEAR, MONTH, DAY, DAYS, EDATE, EOMONTH, WEEKDAY, NETWORKDAYS and WORKDAY.

MATCH supports exact mode 0. Approximate VLOOKUP requires sorted keys. Dates use deterministic UTC interpretation; use ISO dates rather than ambiguous local date strings.

Exports and page macros

Native acceptance has verified CSV, JSON, XLSX and SVG file contents, the configurable saved-report macro, and the report table in Confluence PDF and Word exports. PDF layout was also visually checked. The Word download contains the expected table; its layout in Microsoft Word has not been certified. PDF and Word exports contain the report table, not chart images.
