Product guide

Create your first playable story

In the Project window choose Create > HTF > Dialogue and Quest Story. Unity creates a playable copy of The Lantern Room and selects it. The example has an opening conversation, a two-unit objective and two endings.

To play the supplied story, open Assets/HTF/DialogueQuest/Examples/The Lantern Room.unity and press Play. The sample can save a checkpoint on this device and resume it after exiting Play mode. Change Story language to read the supplied French translation. The story asset in the same folder opens the authoring workspace.

Open the story's Inspector. Change the archivist's opening line, then click Rehearse from opening. Choose "I'll find the slides." Record one unit and keep a checkpoint. Record a second unit to reach Exhibition ready. Restore the checkpoint to return to one of two slides. Return to authoring and rehearse again to try the curator handover.

Write another route

Add a step and give it an author label and player text. Dialogue steps supply one or more labelled responses. Objectives take a positive target and one completion destination. Endings close the route. In the original dialogue, add a response and choose the new step from Goes to. Rehearsal becomes available when every step can be reached from the opening and has a path to an ending. Use Edit > Undo to reverse an authoring change.

Use a story in a game

Add HTF > Dialogue and Quest Player to a GameObject in your scene. Assign the story in the Inspector. Call Begin() from your game's startup code. Subscribe to OnChanged to refresh your UI, including the first step. The current step exposes kind, speaker, text and choices. Pass a choice's zero-based index to Choose. Use AddProgress(units) for the current objective. The call rejects zero, negative or excess units and leaves the position intact.

Save() returns JSON for your game's save slot. Assign the same story and call TryRestore(json) to resume. A missing step, incompatible story, changed step type, malformed checkpoint or invalid objective count leaves the live session intact. Text edits and step order changes preserve saved positions. Increase Save revision when changing the meaning of a route or objective. Keep the asset and its .meta file together when moving a story between projects. A duplicated story has its own save identity.

Change story language through SetLocale. Use DisplayText, DisplaySpeaker and DisplayChoice(index) for the active locale. Call SetLocale("") for the original. Changing language preserves progress. Reference the HTF.DialogueQuest.Runtime assembly from your own assembly definition.

Work with a translator

Select the supplied story asset and choose Translate. Enter a locale, for example fr-FR. Choose a source line to review its original, edit the translation, then Apply line. The coverage indicator counts current reviewed lines. In Rehearse, change Playback language to check replies, objectives, speaker names and endings in context.

Export CSV and give your translator the UTF-8 file. Edit only Translation and preserve the other four columns. Fields support commas, quotes and line breaks. Keep text cells as text in your spreadsheet. Import CSV into the same story and locale. Each updated row uses a stable key, so sorting the sheet or reordering replies preserves meaning. A stale source, unknown or duplicate key, wrong story, wrong locale or malformed row refuses the entire import and leaves earlier work intact. Export a fresh sheet to recover. Keep rows you want to change; omit rows you want to leave alone. A blank translation clears that line to the original.

If an author changes a source line, that line immediately uses its current original at runtime until the translation is reviewed. Inspect the old translation in Translate, edit and choose Apply line. An unconfigured regional locale also uses the original. The bundled fr-FR CSV belongs to the supplied story asset. Export a fresh sheet for a new or duplicated story.

The Inspector checkpoint lasts for the current Unity Editor session. The playable scene demonstrates a local save slot and a simple dialogue UI. Your game can supply its own UI and storage. All authoring, rehearsal and translation exchange run locally.

Buyer questions

Who is this for?

A writer and a Unity developer who want to agree on dialogue, player choices and quest progress before wiring them into the game’s interface.

What can I try immediately?

Open The Lantern Room scene and press Play. Choose the slide-recovery response and record two slides to reach the exhibition ending. The curator response leads straight to a different ending.

Where do I write the dialogue?

Select the story asset in the Project window. Its Inspector exposes the speaker, player-facing line, response labels and destinations.

How do I start my own story?

In the Project window choose Create → HTF → Dialogue and Quest Story. Edit the new starter asset while keeping the supplied example for reference.

Do I need a game scene to try a branch?

The story Inspector has a Rehearse from opening action. It displays the current line and lets you choose an answer or record an objective unit.

Can I change the reply a player sees?

Yes. Edit the response label in the dialogue step and enter rehearsal to read the revised choice in context.

How do I connect a response with the next step?

Pick an existing author label from that response’s Goes to field. You can give several responses different destinations.

How do I add an objective?

Add an Objective step, enter the instruction and unit target, and choose its completion destination. Point a dialogue response to it.

How does an objective finish?

Accepted progress increases its count. Reaching the required number takes the player to the completion destination.

What if my game sends too much progress?

The runtime rejects zero, negative or excess units and keeps the current count. Check the result of AddProgress before treating an event as accepted.

What does validation catch?

It checks step IDs, authored text, response labels and destinations, positive objective targets, reachability from the opening, and whether each step has a path to an ending.

How do I repair a broken route?

Read the Inspector warning, correct the offending field, and rehearse again when the story validates. For an unintended authoring edit, use Unity’s Undo.

Can I return partway through an objective?

Yes. Keep a checkpoint at one of two slides, enter the ending, then restore. The example returns to the objective with one slide recorded.

What happens to my Inspector checkpoint when the Editor closes?

It is scoped to the current Editor session. Use the runtime save API and your game’s storage for a playthrough that must survive a restart.

Where is progress saved?

The example demonstrates a local device save slot that can be resumed after exiting Play mode. In your own game, choose the storage method. The player component returns a JSON string from Save and accepts it through TryRestore.

Can I revise a line after a player saves?

Text edits can retain the saved position when the story identity, revision, step type and objective count remain compatible.

What if I reorder the steps?

Saves resolve a stable step ID. Reordering the list does not change that ID.

Can a checkpoint from one story resume its duplicate?

A duplicated story has its own Unity asset identity. The component rejects a checkpoint belonging to a different story.

What happens to an active playthrough if restoration fails?

An incompatible story or revision, missing step, changed step type, malformed checkpoint or invalid objective count leaves the current valid session in place.

How should I handle revisions that change the story’s meaning?

Raise the asset’s Save revision. Your game can then decide how to handle players carrying an older checkpoint.

How do I connect my dialogue screen?

Assign the story to a Dialogue and Quest Player component, subscribe to OnChanged and call Begin. Use DisplaySpeaker, DisplayText and DisplayChoice for the selected language. Pass the selected response index to Choose.

How does my gameplay trigger progress?

When your interaction succeeds, pass the number of units to AddProgress. In the example, finding a slide can contribute one unit.

Can each player have a separate playthrough?

A runtime session holds its own current step and count. Your game chooses how to associate a session and saved data with each player.

What needs to stay with the asset when I move it between Unity projects?

Keep the story and its Unity .meta file together. The asset identity is part of the save contract.

Does the package need an account or hosted dialogue service?

Authoring and runtime logic operate locally and require no Workbench account or hosted story service.

Which Unity version was used for native verification?

Unity 6.3 LTS, Editor 6000.3.27f2, on Windows. Other Editor versions and target platforms are outside the stated verification.

What information helps with support?

Send your Unity Editor version, the affected step label, the operation you tried and the warning text. A small example with substitute lines is sufficient for a confidential story.

What does a translator receive?

Export a UTF-8 CSV for the story and locale. It contains Story, Locale, Key, Source and Translation. Edit the Translation column. Quoted speech, commas, Unicode characters and line breaks are supported.

Can a translator return only finished lines?

Yes. Keep the rows to update and omit the others. Stable keys identify the source text and choices even if the sheet or responses have been reordered. A blank translation on an included row clears that line back to its original.

What happens if a translation sheet is outdated?

A changed source, unknown or duplicate key, mismatched story or locale, or malformed row causes the whole import to be declined. Existing translations survive. Export a fresh sheet from the same story and locale to retry.

What will players see if a translation is missing?

The player uses the current original for a missing or outdated line. Locale matching is exact. A story configured for fr-FR falls back to its original when asked for an unconfigured regional locale.

Can I check translated choices before integrating them?

Use the Inspector’s Playback language control during rehearsal, or switch Story language in the playable sample. The included French text covers the archivist, opening, both responses, objective and both endings. Switching language preserves the player’s position.
