Save. Inspect. Recover.

Save, inspect, migrate and recover local game saves in Unreal Engine. SaveGuard Studio 1.0.0 is submitted to Fab for review. The submitted Code Plugin includes Blueprint-callable and C++ APIs, the native Inspector and documentation.

Save with confidence

World and player saves, multiple slots, synchronous and asynchronous file operations, and Blueprint-callable and C++ APIs.

Review changes before release

Inspect slot health, compare snapshots and rehearse migrations in memory without changing the original save.

Practise recovery

Retain configurable backups and explicitly recover a valid earlier save, quarantining the previous primary file.

Fab confirmed receipt of version 1.0.0 on 4 November 2026. The production package passed UE 5.8.4 Editor, Windows Development and Shipping builds, an exact-archive clean load, and focused native Inspector checks.

Where it runs

Verified on Unreal Engine 5.8.4, Windows / Win64. Saves stay local; no HTF account, hosted service, database or telemetry connection is required. Cloud adapters and encryption are not included. Checksums detect accidental changes, not malicious tampering. Other engine versions, platforms, consoles, dedicated servers and network replication are not claimed.
