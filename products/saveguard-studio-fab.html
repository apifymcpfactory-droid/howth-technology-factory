What we are building

An Unreal Engine toolkit in development for saving game progress, reviewing changes and recovering earlier saves. The features below describe the intended product, not a finished release.

Save with confidence

Planned support for world and player saves, multiple slots, background saving, Blueprints and C++.

Review changes before release

Planned save inspection, comparisons and migration rehearsals to check what a game update will change.

Practise recovery

Planned backups, rollback and interrupted-write tests to help developers check recovery before releasing a game.

Development progress

Development has started. Engine integration, data recovery, compatibility, performance and usability must be tested before release. No Fab package has been submitted.

Complete feature coverage, a clear interface, useful documentation and marketplace checks are required before submission. Performance and compatibility claims will follow testing.

Where it runs

The planned toolkit runs in the developer’s Unreal Engine project. Any optional platform storage connection will use the customer’s own service account. Supported engine versions and platforms will be published after testing.
