Read the installation and use guide

Start with an editable warehouse scene

FlowDock Studio is a 3D scene and mesh kit. You can use the supplied layout as your starting point or rearrange its named parts for your own visualization. It is not an add-on: you do not install or activate it through Blender's extensions settings.

Your workflow: Open the scene → Choose an area → Select its parts → Edit the layout → Check and revise → Render your view.

You make each decision and perform each step in your application. This sequence describes the manual workflow; it is not an automated FlowDock command.

1. Download and extract

  1. Download the product ZIP from your Superhive purchase.
  2. Extract the complete archive into a folder you can find again. Do not work directly inside the compressed ZIP.
  3. Keep the folder structure intact. In particular, keep the OBJ, MTL and supplied texture resources together.
  4. Keep an unchanged copy of the download. Save your own scene edits under a different filename.

2. Open the Blender scene

  1. Use Blender 5.3.0 on Windows with Eevee, the configuration supported by this release. Other versions, operating systems and render engines are not covered by this compatibility claim.
  2. In Blender, choose File > Open and select FlowDock-Studio.blend in the extracted product folder.
  3. Use File > Save As to make a working copy before changing the layout or materials.
  4. Inspect the scene in the viewport. Use the Outliner to find named objects, and refer to docs/asset-catalog.json for the supplied mesh-part names.

The kit contains 215 named mesh parts, including repeated components of larger equipment. A complete rack, pallet or workstation may be made from several objects.

3. Make a first useful view

  1. Choose what you need to explain: receiving, storage and racking, picking and packing, or dispatch.
  2. Start with the supplied scene and inspect the relevant area. The reference-renders folder provides five examples of the scene's appearance.
  3. For a render of the scene's active camera, use Render > Render Image. Save the result from the render window when you are happy with it.
  4. To tell a different story, reposition your camera and render again. The reference PNG files are examples, not a selectable camera-preset feature.

Your computer, application version, render settings and changes to the scene affect the result and rendering time. No fixed performance or hardware requirement is claimed.

4. Adapt the layout

  1. Work in your saved copy and select the objects you want to change.
  2. When moving an equipment assembly, select all its related parts. Moving only one rack beam or pallet slat will not move the whole assembly.
  3. Move, rotate, duplicate or hide the selected parts to suit your composition.
  4. Inspect the result from more than one angle for overlaps or missing components, then save your working copy.

The kit provides editable mesh objects. It does not provide automatic warehouse layout generation, snapping tools, simulation or collision validation.

5. Change materials

Select an object and inspect its assigned material in Blender's Material Properties. The supplied materials use a coordinated dark blue, silver, cyan and orange palette. Shared materials can be used by several objects, so a change may affect more than the currently selected part. Save a copy and check the whole scene after making changes.

6. Use another application

Choose a file from exports that your application supports:

  • FlowDock-Studio.fbx — FBX scene export.
  • FlowDock-Studio.glb — binary glTF scene export.
  • FlowDock-Studio.obj — OBJ geometry, with its companion FlowDock-Studio.mtl and supplied resources.
  • FlowDock-Studio.usdc — USD scene export.

Use your application's importer and inspect the resulting objects, materials, scale and orientation. Different importers may interpret the same export differently. Adjust the destination settings as needed; the presence of an export does not certify compatibility with a specific game engine or application. No rigged-vehicle or animated-conveyor workflow is supplied.

  • docs/VALIDATION.txt records the checks described there. These are scoped checks, not a guarantee for every application or future software version.

Troubleshooting

The ZIP will not install as an add-on: extract it and open the .blend scene instead. It is not an extension package.

A material is missing after import: confirm that the complete archive was extracted, retain the companion material and texture files, and check your importer's material options.

Only part of an object moved: undo the move, identify the related named components, and select the whole set before trying again.

The imported scene looks different: check the destination application's material, lighting, scale and orientation settings. Interchange formats do not guarantee identical appearance.

The scene does not open in your Blender version: confirm you are using Blender 5.3.0 on Windows and contact support with the filename and exact error. Older and future releases are not automatically covered.

Questions before you buy

What is FlowDock Studio?

FlowDock Studio is an editable 3D warehouse scene and modular mesh kit. Use it to create warehouse visualizations, training illustrations, operational stories and environment scenes. It supplies the scene and objects; it does not run warehouse operations.

Who is this kit for?

It is for visualization artists, training-content teams and environment builders who need recognizable warehouse equipment in one coordinated scene. Basic Blender navigation and object editing will help you adapt the layout.

What problem does the kit help me solve?

It gives you a warehouse starting point with matching equipment, so you can focus on your layout, camera views and explanation instead of modelling every rack, pallet and workstation from scratch.

What is included in the download?

Editable Blender source; FBX, GLB, OBJ with MTL and USD (.usdc) exports; a named asset catalogue; a buyer README; validation notes; and five reference renders. The kit contains 215 named mesh parts.

Are these 215 different finished props?

No. The count is 215 named mesh parts, including repeated parts and components of larger objects. Rack posts and beams, pallet pieces and conveyor rollers contribute to that count. It is not a claim of 215 unique equipment designs.

Which warehouse activities can I illustrate?

The scene covers inbound receiving, storage and racking, picking and packing, and outbound dispatch. Show the whole layout or frame one area for a focused explanation. These are visual arrangements, not executable process simulations.

What equipment will I find?

The scene includes racks, pallets, cartons, dock doors, conveyors, workstations, barriers, packing equipment and a generic forklift. The named catalogue helps you identify the component parts.

Can I change the warehouse layout?

Yes. Save a working copy of the Blender scene, then move, duplicate, rotate or hide its mesh objects. Equipment can contain several separate parts, so select all of the relevant parts when moving or duplicating it.

Can I use just one area or a few objects?

Yes. Work from a copy of the scene and keep the parts you need for your composition. Check for related components before removing the rest; the asset count includes parts of larger objects.

Is this a Blender add-on?

No. It is a scene and asset download. Extract the ZIP and open the .blend file; do not install the ZIP as an extension or add-on. No FlowDock add-on activation is needed.

Which Blender version should I use?

This release's supported configuration is Blender 5.3.0 on Windows, using Eevee. Other Blender versions, operating systems and render engines are not covered by this compatibility claim. If you need a different configuration, ask before purchasing.

Can I use the kit outside Blender?

FBX, GLB, OBJ with MTL and USD (.usdc) files are included for applications that support those formats. Import settings, materials, scale and performance vary by application. This listing does not certify a particular game engine or non-Blender application.

Which file should I open first?

For Blender, open FlowDock-Studio.blend after extracting the download. Use an export from the exports folder only when your destination application needs that format. Keep the supplied folder structure intact.

Why are OBJ, MTL and a texture folder supplied together?

OBJ material references can depend on the companion MTL file and supplied texture resources. Keep those files and their relative folders together when importing. Copying only the OBJ can result in missing or different materials.

Will every export look identical in another application?

Not necessarily. Different importers interpret materials, lighting, geometry and units differently. Inspect the imported scene and adjust the destination application's material and display settings as needed. The native Blender scene is the source for layout and material editing.

Can I change the colours?

Yes. The Blender scene includes editable materials. Its coordinated dark blue, silver, cyan and orange palette is a starting point. A shared material change can affect several objects, so save a copy and check the result across the scene.

Are the gallery images photographs?

No. They are renders of the supplied 3D scene. Any explanatory captions are separate from the model. The download also includes five reference renders; those images are references, not five separate warehouse scenes.

Are the reference views selectable camera presets?

The included reference renders are image files. This listing does not promise a five-camera preset system. You can position a camera in the editable scene to create your own views.

Is the forklift rigged, and do the conveyors move automatically?

No rigged-vehicle or animated-conveyor workflow is included. These are static scene objects. Animation, interactive behaviour and simulation would be additional work in your project.
