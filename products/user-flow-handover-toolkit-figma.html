What should I know before using it?

Connections are static editable vectors. Moving cards does not automatically reconnect paths. Adjust them manually or create a revised board. Conditional links show possibilities, not evaluated runtime behaviour. Up to 80 screens, 240 links and 20,000 inspected layers.

What if a screen preview cannot refresh?

The existing preview stays in place and the screen remains pending for another attempt. Retry when rendering is available again or the original preview card has been restored. Successful previews stay current, and manual routes, labels, positions and notes are preserved. This source-preview workflow runs in Figma; the browser demo does not simulate rendering failures or saved-board refresh.

Privacy and data

The plugin allows no external network domains. It has no HTF server, analytics SDK or automatic AI service. Figma manages its own document storage and payment services. Review downloads may contain private text, screen images, names and IDs; share them carefully.

The browser demo contains fictional sample data, with changes held in memory until refresh. It never connects to your Figma file or processes payments. This marketing page uses website analytics under our privacy notice.
