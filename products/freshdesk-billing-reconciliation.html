Compare a billed period

A billing reviewer needs two complete JSON snapshots from the app. Keep the first when you bill and compare it with a later observation of the same inclusive UTC dates. Both files must cover the same Freshdesk account and agent visibility. An earlier snapshot is essential to identify what has changed since billing.

  1. Choose the original file under Statement used for billing. Choose the later file under Latest statement for the same period.
  2. Select Compare time entries. Review the original and current billable minutes, then check the affected entries by ticket ID. An entry marked No longer returned warrants checking in Freshdesk before you adjust a bill.
  3. Select Download changes as CSV to keep the before and after values for every changed entry. The screen shows up to 200 changed entries. When both files agree, the app reports that no entries changed.

File handling and limits

Comparison runs in your browser. Each input file can be up to 16 MiB. If a file is incomplete or the dates, account or visibility differ, select a matching pair and try again. Store downloaded files with your billing records. They contain ticket and time-entry identifiers, durations and billable flags.

The result measures billable minutes. Your billing team applies rates and decides whether to adjust an invoice. The comparison leaves Freshdesk time entries unchanged.
