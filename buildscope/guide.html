A passing scan means only that the configured checks passed against the project state BuildScope could observe. It is not certification that a release is defect-free, secure, performant on untested hardware or accepted by a marketplace.

Start a review

  1. Enable BuildScope and restart Unreal Editor if prompted.
  2. Create a BuildScope Profile in the Content Browser.
  3. Give every rule a stable ID, clear label, supported rule kind and subject.
  4. Open Window → BuildScope Release Readiness.
  5. Select the profile and run the bounded project scan.

Read the evidence honestly

Passed, warning, failed, skipped and unavailable are distinct states. Missing or inaccessible evidence is never converted into a pass. Version 1.0 supports required project files, enabled plugins, configuration values, required maps, permitted target platforms and a project Content size budget.

Compare a later candidate

Save a reviewed scan as the local baseline for that profile. BuildScope loads it only when the schema version and profile identity match. Rerun the scan after project changes to review added, removed, changed and unchanged findings.

Export the handoff

Export versioned JSON, findings CSV or a self-contained offline HTML report under Saved/BuildScope/Exports. Baselines remain under Saved/BuildScope/Baselines. Review every export before sharing it.

Compatibility

The submitted release targets Unreal Engine 5.8 on the Windows editor / Win64. Source is included. Runtime game support, cloud upload, telemetry and an online account are not included.
