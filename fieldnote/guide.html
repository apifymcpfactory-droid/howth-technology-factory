Fieldnote reports captured events and researcher annotations. It does not infer emotion, intent, demographics, accessibility status, design quality or causation.

Before a session

  1. Create a Fieldnote Study data asset.
  2. Enter a stable study name and one research question.
  3. Add ordered tasks with a stable ID, participant prompt, observable success definition and sensible time limit.
  4. Enable only the capture fields the study requires.
  5. Use pseudonymous participant labels. Do not enter names, email addresses, passwords, payment data or private chat content.

Fieldnote rejects incomplete plans, duplicate task IDs and fields outside its documented limits.

Run the session

  1. Start a session with the accepted plan, pseudonymous participant label and build label.
  2. Start each task when the participant begins it.
  3. Record Succeeded, Failed, Abandoned or Not Observed.
  4. Add concise timestamped observations, friction points, questions, positive moments, defects or researcher notes.
  5. End the session cleanly.

Each accepted change is checkpointed locally. If a write fails, the in-memory change is rolled back and the previous completed checkpoint remains intact.

Recover an interrupted session

The Fieldnote workspace identifies sessions that did not end cleanly. Recovery adds an explicit marker. Existing timestamps remain intact and subsequent evidence continues from the last recorded task or marker time.

Review and export

An accepted export creates a self-contained folder under Saved/Fieldnote/Exports/<session-id>/ containing an offline HTML report, task CSV, marker CSV and versioned JSON evidence file. Review every file before sharing it. Fieldnote does not upload the files automatically.

Privacy and retention

The project owner controls access, retention and deletion. Document those rules before a study begins. Fieldnote does not provide recruitment, participant consent management, video conferencing, biometric analysis or cloud device management.

Current compatibility boundary

The first release targets Unreal Engine 5.8 on Windows 64-bit editor and Win64 Development playtest builds. Compatibility is not claimed until the final packaged candidate passes its recorded acceptance checks.

Need help?

Read the Fieldnote support guidance. Never send passwords, payment data or unredacted participant information.
