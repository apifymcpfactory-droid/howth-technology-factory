Fieldnote has been submitted to Fab for review and is not yet available to purchase. This page defines the evidence needed for support once the release is accepted.

Developed and in ReviewVersion 1.0.0 is awaiting Fab approval and automatic publication.

Include

  • Fieldnote version
  • Unreal Engine version
  • Windows version
  • Editor or Win64 Development build
  • Smallest reproducible steps
  • Exact Fieldnote error message

Do not include

  • Passwords or API keys
  • Payment data
  • Private chat content
  • Unredacted participant identities
  • Session files you are not authorised to share

Contact

Email support@howthtechnologyfactory.pro. Include “Fieldnote” in the subject. If a minimal session fixture is needed, support will ask for a redacted copy; do not attach raw participant data by default.

The first release scope is Unreal Engine 5.8, Windows editor and Win64 Development playtests. Other engines, operating systems and targets are unsupported unless the final listing and release notes explicitly say otherwise.
