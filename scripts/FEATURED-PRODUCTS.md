# Featured product carousel

The homepage retains its large copy/artwork layout. The catalogue uses the existing compact card. Both are generated from `products/featured.json`, in the order listed there.

To feature a new product, use its existing product page, catalogue record and artwork. Place newly published products first by marketplace publication date. Link a working browser demo where available. Otherwise, the slide opens the product page. Run `node scripts/build-product-grids.mjs` and the catalogue/featured-product checks. Up to **50** products can be featured. The full catalogue can contain more.

Metadata includes the short navigation label, platform, headline lines, first emphasized line, introduction, pricing/availability wording, demo, optional marketplace link, artwork/alt text, caption and facts. There is no fabricated product placeholder or duplicated slide used to fill the shelf. Do not claim an unavailable checkout or omit a product's development status when that changes the buying decision.

Navigation uses Previous/Next arrows and a pause/resume control. Rotation runs every five seconds and pauses on hover, focus, hidden tabs and offscreen sections. Reduced-motion preferences disable automatic rotation. Using an arrow or a touch swipe pauses automatic rotation until explicitly resumed. Without JavaScript, the first feature and full product grid remain available.

Product cards use existing feature artwork where available. Other products have labelled workflow illustrations generated by scripts/build-product-artwork.mjs. They are not represented as application screenshots.
